# B1 (Beginner 1):
This is the probably one of the first project ur doing so let me help u out a bit (and tell u where i made a mistake once). Traditionally, one of the first projects that anyone makes with a new arduino kit or something is a blink LED. So here check this code out and give it a whirl. Change values, put another outputing thingy or whatever its ur playground!

## Materials:
1. 1 LED (any colour you like)
2. 1 220 ohm Resistor (EXTREMELY IMPORTANT IF U DONT WANNA BURN UR LED)
3. 2 jumper cables (to connect ur beautiful circuit)
4. A breadboard (small or big or whatever, its a small project)
5. Arduino UNO (or any microcontroller ur comfortable with but the code is for an ARDUINO)
6. An Arduino Data Cable (i dont think an explanation is needed)

## Process:
- Take ur LED and put it in the breadboard into two holes with a different number (number in the breadboard i mean) and not in different letter (it wont let current pass thru)
- take a resistor and connect it in the same number line as that of the long wire part (anode) of the LED. the other part of the resistor can be place anywhere but on the same number line.
- take a jumper cable and connect the open end of the resistor in the same number line to the pin hole 7 on the arduino (as per the code)
- take another jumper cable and connect it from the other wire of the LED (cathode) on the same number line to any GND pin hole in ur arduino.
- Take the code in the repository and download it. Once downloaded, open with Arduino IDE and upload the sketch to your arduino.
- Enjoy the fake ticking time bomb! (or slower depending on the delay)
